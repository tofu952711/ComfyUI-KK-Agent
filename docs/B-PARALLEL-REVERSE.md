# B链路按实际段数并发反推

本次修改只在B链路生效。A链路不足32秒时仍直接反推，调用次数、规则和视频输出策略不变。

## 执行过程

1. 原有分段AI按照「链路B：分段规定」调用工具实际裁出视频。
2. 主AI基于参考图、全片概览、原声证据和B反推规则，生成六项简短共用设定：全片概要、人物服装、商品适配、场景光线、声音身份、跨段衔接。
3. 根据工具成功返回的实际段数创建同样数量的独立子智能体。两段派两个，四段派四个，最多五个；具体分几段仍由用户的分段规定决定。
4. 子智能体共用参考图和主AI设定，只接收自己段落的抽帧与转写，以及边界前后至多0.5秒的上下文。拼图会重新组合，避免将整张跨段拼图重复发给所有子任务。
5. 每个子智能体沿用用户填写的B反推规则原文，仅生成自己一段的完整提示词。工具时间使用原片秒数，交付正文时间从该段0秒开始。
6. 全部子任务成功后，主AI必须再次接收全部草稿、原始用户要求、B创作规则、共用设定和素材证据，复核人物商品声线场景、跨段位置持握开封状态、时间轴与镜头、对白时长及衔接、商品事实和固定结构。发现明确问题时只返回必要的局部原文替换，不重写整篇。
7. 程序验证主AI复核结果及修改引用，确认没有改变时间数字、章节顺序或参考编号，应用修正后按实际段号输出最终正文。复核失败、格式无效、修改不能唯一匹配、检查项未通过时明确报错，不跳过复核。视频保存仍由原来的SaveVideo分支负责。

不需要重新接线，不增加工作流必填参数。`DSH_FullVideoAgent`和分离的`DSH_VideoSegments → DSH_VideoReverse`两种B入口均使用此实现。

## 隔离与音频

每个子任务使用独立的Bridge、Harness运行时、会话、审计文件、工具输出和可写缓存。原片与预解码帧仅用于读取。子任务不能重新分段。

关闭「保留音轨」仅影响导出视频；分析仍读取原片音轨及已有转写。说话人聚类按整条原录音计算，编号以全片首次出现顺序为准；已有的全片说话人证据可以复用。

## 结果、耗时与失败

结果保存在ComfyUI用户目录的：

`default/dsh_bridge/b-results/<run_id>/`

- `shared-context.json`：主AI共用设定。
- `segment-N.json`：各段正文、用量、工具证据、耗时、原片与局部时间映射。
- `draft-prompts.txt`：子任务全部完成后的未复核汇总草稿。
- `review-response.json`：最终复核调用返回的原始内容和用量，失败时也尽量保留。
- `review.json`：主AI六项检查、发现的问题、局部修改、复核耗时和用量。
- `segment-N-reviewed.json`：通过复核及修改验证后的各段正文，原始`segment-N.json`保留不覆盖。
- `prompts.txt`：只有最终复核通过后才生成的成品正文。
- `parallel-summary.json`：主AI准备耗时、并发阶段实际耗时、各子任务耗时及最终复核记录。
- `status.json`：执行状态、已完成段号和错误。

请求审计仍在`request-audit/`，分别标记`b-coordinator`、`b-reverse-N`与`b-review`。最终复核的Token记录为`phase=review`、`b_agent_role=reviewer`。Token耗时记录增加`b_agent_role`和`segment_index`用于区分并发请求；各请求耗时之和可能大于墙钟耗时。B链路最终分析证据另外提供`timings.reverse_review_seconds`，并发耗时不包含复核耗时。

反推阶段的整体超时覆盖主AI准备、全部子任务及最终复核。ComfyUI停止信号及超时会终止本次B任务的运行实例并等待清理。某段失败时不启动最终复核；某段或最终复核失败时，不输出全部完成的提示词，已经成功的各段草稿仍保存在上述目录。接口请求继续使用原有的请求级重试机制，不自动将所有段重新跑一遍。

并发会重复发送共用规则与参考图，费用可能上升。实际提速受模型接口并发配额、队列、段落长度和工具调用轮数影响。本地验证使用模拟接口；不以模拟耗时承诺真实接口加速倍数。

## 片尾抽帧容错

B链路预处理及子任务补帧遇到“请求时间在最后真实帧PTS之后、但仍小于视频总时长”的情况，会核对实际可解码范围并跳过该采样，不补造帧、不改变原视频时长或裁切终点。跳过的时间写入`preparation.json`的`coverage.skipped_tail_times`及任务工具目录的`b_tail_sampling.json`。全片无画面、时间参数非法、中段解码缺失或解码器本身报错仍明确失败。A链路的采样与预处理实现保持不变。
