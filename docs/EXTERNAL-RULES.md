# 规则填写

| 输入框 | 用途 | 何时填写 |
| --- | --- | --- |
| 本次用户要求 | 本次任务、参考图用途、改编目标 | A/B 共用 |
| 系统提示词（原Skill正文） | A 链路反推规则 | 不足 32 秒 |
| 链路B：分段规定 | AI 判断切点并调用工具裁切的规则 | 32—60 秒 |
| 链路B：反推提示词规定 | 裁切成功后生成提示词的规则 | 32—60 秒 |

规则框默认空白。可粘贴完整规则正文，也可右键「转为输入」，连接 Text (Multiline)、PrimitiveStringMultiline 或其他 STRING 文本节点。填写正文，不要填文件路径；不需要 YAML 头部。

A 只读取 A 规则，B 只读取自己的两套规则；当前链路必需的规则为空时会报错。用户要求与系统规则分别发送，视频信息、转写、参考图编号及抽帧拼图作为素材资料提供。规则决定最终文字内容和格式，视频时长决定 A/B 路由。

`image1—image10` 是通用参考图，含义由你说明。例如「image1 为人物外貌，image2 为目标商品」。未连接的图片编号不重排。

插件附带的 14 套 Skill 位于 `vendor/skills/`，包含视频复刻、人物替换、换装、风格及镜头写作等内容。视频反推节点不自动加载这些内置创作规则；需要使用时自行将所需正文填入对应框。

规则文本会随工作流 JSON 保存。分享前检查是否包含不希望公开的内容。
