# Token速度监视

`DSH_FullVideoAgent` 节点内显示 Token 速度面板，分段、反推、工具续轮和复核分别记录每一次模型请求；重试也作为独立请求记录。

- **请求平均 tok/s**：已报告的输出 token 总数 ÷ 对应请求耗时总和，包含首内容等待；不包含本地预处理和请求间工具耗时。不是各次速度的算术平均，也不是排除延迟后的纯解码速度。
- **有效 tok/s**：输出 token 总数 ÷ 当前任务总用时，包含预处理、工具、重试与复核。只在所有已结束请求都有用量时显示；有失败请求未返回用量时留空。
- **首内容等待**：请求开始至首个可观测文字、思考文字或工具参数内容的时间。接口未发送的内部推理不可观测，不能当成模型真实首个内部token的时间。
- **输出 token**：使用 SDK 规范化后的接口 `outputTokens`，并保留完整用量字段。推理 token 不额外相加，避免重复计数。

多数接口在请求结束时才报告 token 用量。运行中显示耗时和接收字符数；字符和流式数据块不充当 token，不估算瞬时 tok/s。接口未返回用量时明确显示“无法计算”，不会用 0 冒充速度。

节点的“请求token用量”默认开启，对 OpenAI 兼容接口发送 `stream_options: {include_usage: true}`。如接口拒绝该参数可关闭，监视仍记录耗时；DeepSeek Messages使用其协议自带用量。面板/聊天连接仍保留原先兼容设置，若需主动请求用量可在插件配置设置 `stream_usage: true`。

统计保存到 ComfyUI 用户目录的 `default/dsh_bridge/token-speed/`：每个节点一份最新 JSON，`history.jsonl` 保存历史快照；历史达到 5 MiB 时轮换保留上一份。统计只保存模型名称、随机请求标识、时间、字符数、token计数和结束状态，不保存密钥、素材或提示词。临时 Harness 会话删除后仍能查看，重新加载工作流会恢复该节点最近统计；服务重启遗留的运行状态显示已中断。

控制台同时打印每次请求 tok/s。节点“分析证据”输出包含 `token_speed`；本地接口 `GET /dsh_bridge/token_speed?node_id=92` 返回最新统计。
