# 视频反推节点

推荐导入 [并行示例](../examples/parallel_video_workflow.json)。它包含 `KK agent 视频反推`、`DSH 独立反推` 和标准 SaveVideo 分支。`DSH Agent 完整视频反推` 也可使用，按串行方式返回文字及分段结果。

## 输入和输出

- 原视频：连接 ComfyUI 的 VIDEO 输出，支持有效时长 60 秒以内的视频。
- 参考图：`image1—image10` 均可选，在用户要求或规则中说明各图职责。
- 接口：填写自己的 Key、地址、模型及协议，见 [接口配置](APIMART.md)。
- 文本：填写本次用户要求及当前链路对应的规则，见 [规则填写](EXTERNAL-RULES.md)。
- 输出：提示词、分析证据、状态，以及最多五个 VIDEO；并行入口另有「反推资料」输出。

并行入口的提示词请从 `DSH 独立反推` 取得。视频保存方式见 [视频分段](VIDEO-SEGMENTS.md)。

## 素材分析

插件准备全片概览、密集动作帧、切点前后帧、视频信息、参考图映射及可用的音轨转写。agent 可按需调用视频工具补看细节、复核声音或估计说话人。切点和声音变化是分析线索，不等同于已核实的镜头或人数。

参考图与视频拼图合计每阶段最多 50 张；超限或接口拒绝图片时会报错。自动转写可能有误，精确台词、声音身份和人数仍需结合原片核对。

## 模型与依赖

完整 Windows 包内置 SenseVoiceSmall INT8；「本地SenseVoice模型目录」留空即可，也支持插件相对路径、绝对路径或 `DSH_BRIDGE_ASR_MODEL_DIR` 环境变量。任务运行时不下载模型。

声音工具使用 ComfyUI 的 Python 和 CPU。缺少语音运行库时，用 ComfyUI 的 Python 安装 `requirements.txt`。说话人模型配置见 [CPU 说话人分析](SPEAKER-ANALYSIS.md)。

## 常见问题

- 找不到节点：确认插件放在 `custom_nodes/ComfyUI-DSH-Bridge/`，重启 ComfyUI 并刷新浏览器，查看启动日志是否加载成功。
- 提示填写规则：不足 32 秒需要 A 系统规则；32—60 秒需要两套 B 规则。
- 没有保存视频：分流入口的 A 请将 video1 连接保存节点（可先接人脸打码），「反推资料」连接独立反推节点；B 请连接 SaveVideo 并检查分段工具是否成功。旧完整视频单节点的 A 仍不输出视频。
- 输出被截断：提高「模型输出上限」并确认接口支持该值。
- 超时或接口报错：检查连接、模型权限和输出长度，按需增加 `timeout_s`。

每次节点执行使用独立临时运行目录和会话。规则与 Key 保存在你自己保存的工作流中；统计及请求审计位于 ComfyUI 用户目录 `default/dsh_bridge/`，请勿把整个用户目录作为插件发布。


B 链路最终审核可在节点末尾的「链路B：审核规定」多行文本框中编辑，也可右键转为输入连接外部文本节点。默认显示原审核全文，旧工作流未保存该字段时使用相同默认文本；明确清空后，B 会在调用接口前提示填写，A 不读取此字段。审核范围以文本框内容为准，不再由程序固定为两项；修改检查项时同步修改 JSON 示例中的 checks 名称，保留 status、checks、issues、edits 及逐字替换结构。该文本随工作流保存。
