# 视频分段与保存

| 原视频实际时长 | 处理 |
| --- | --- |
| 大于 0 且不足 32 秒 | A 链路直接反推，不输出 VIDEO |
| 32—60 秒，含边界 | B 链路由 AI 裁出 2—5 段，再独立反推 |
| 超过 60 秒或时长无效 | 报错，请先处理原视频 |

时长不四舍五入，提示词不能改变路由。B 的「分段规定」和「反推提示词规定」均须填写，不使用 A 的系统规则。

## B 链路

1. AI 根据原片、参考图、本次用户要求和 B 分段规定选择切点。
2. AI 调用 `set_video_segments`，FFmpeg 实际裁切并校验连续覆盖原片的结果。
3. 分段视频从 `video1—videoN` 输出；独立反推使用 B 反推规定、分段范围及共用素材生成提示词。

未调用工具、裁切失败或反推为空会报错。未使用的 VIDEO 输出会阻止对应下游分支执行。

## 保存接线

使用 `parallel_video_workflow.json`：`KK agent 视频反推` 的 `video1—video5` 接标准 SaveVideo；「反推资料」接 `DSH 独立反推`。分段完成后，SaveVideo 可在反推期间保存视频。

输出目录、前缀、格式和编码由各 SaveVideo 决定。插件临时分析目录会随任务清理，要保留视频需连接 SaveVideo。

「保留音轨」默认开启，关闭后分段成品移除音轨；分析阶段仍可读取原音轨进行转写及说话人分析。A 没有视频输出。
